# Лабораторная работа №1 — анализ данных кофейни

Учебный проект по первичному исследованию и оценке качества данных.

## Структура проекта

- `README.md` — описание проекта и инструкция запуска.
- `data/coffee_shop_sales.csv` — исходный учебный датасет.
- `notebooks/01_data_understanding.ipynb` — воспроизводимый ноутбук с анализом.
- `report/quality_report.md` — текстовый отчёт о качестве данных.
- `.gitignore` — исключения для Git.

## Запуск в Google Colab

1. Распакуйте архив проекта на компьютере.
2. Откройте [Google Colab](https://colab.research.google.com/).
3. Загрузите `notebooks/01_data_understanding.ipynb`.
4. В Colab создайте каталог `data` (значок папки слева → новая папка).
5. Загрузите в него `data/coffee_shop_sales.csv`.
6. Выберите «Среда выполнения» → «Выполнить все».

## Запуск локально

Из корневого каталога проекта установите зависимости:

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

Затем запустите:

```bash
jupyter notebook
```

Откройте `notebooks/01_data_understanding.ipynb` и выполните ячейки сверху вниз. Путь к CSV в ноутбуке рассчитан на запуск из каталога `notebooks` или из корня проекта.

## Примечание о данных

Датасет является синтетическим и используется только для учебной работы. Перед практическим применением выводов на реальном бизнесе потребовались бы проверка источника и подтверждение бизнес-правил.
